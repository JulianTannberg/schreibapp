ESSEN TRACKER – UPDATE v51

Historische Tage auf der Heute-Seite:
- Wasser zeigt jetzt ausschließlich die Einträge des ausgewählten Tages.
- Bei vergangenen Tagen steht das Datum zusätzlich klein dabei.
- Freie-Tage-Serien (z.B. bierfrei / süßigkeitenfrei) werden auf den ausgewählten Tag zurückgerechnet.
- Beim Gewicht werden nur Messungen bis einschließlich des ausgewählten Tages berücksichtigt.
- Eine spätere Messung (z.B. vom 30.09.) kann dadurch nicht mehr auf einem früheren Tag (z.B. 17.09.) erscheinen.
- Wenn am ausgewählten Tag selbst keine Messung vorliegt, wird höchstens der letzte Stand VOR diesem Tag angezeigt und entsprechend gekennzeichnet.
- Gibt es bis zu diesem Tag überhaupt noch keine Messung, wird die Gewichtskarte ausgeblendet.

Alle Änderungen aus v50 (Fotopool, Monatsbericht, kleine Sprüche usw.) bleiben erhalten.
